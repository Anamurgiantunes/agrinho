# Projeto Agrinho 2026 - "Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente".

# Sobre: 
Página da web sobre o tema desenvolvimento sustentável na agricultura. O site explora a história e a importância do plantio direto, uma técnica revolucionária nascida no Paraná que transforma a produção no campo, protegendo os recursos naturais e promovendo a sustentabilidade que move o nosso estado.

# Recursos utilizados:
- HTML
- CSS
- JavaScript
